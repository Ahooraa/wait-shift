# Globus Compute dataset

## What it is
Trace of Python functions run on the Globus Compute platform, 28 Nov 2022 to 3 Jul 2023: 2,121,472 jobs by 252 users over 580 endpoints; 277,386 registered functions with 1,847 distinct bodies in 29 clusters (as reported in [[jayanthi-2026-quantum]], p. 16). Data statement gives a Zenodo record (p. 35).

## Relevance to this project
Scientific-computing workload, not business workflows; no DAG structure used by Jayanthi 2026.
