# EdgeCloudSim

## What it is
Simulation environment for performance evaluation of edge computing systems (Sonmez, Ozgovde, Ersoy, 2018; ref. [39] in Lei et al.).

## The evidence
Lei et al. implement their full scheduling framework on a testbed built on it (Sect. 5.1.4, p. 10) in [[lei-2026-adaptive]].

## Relevance to this project
Candidate simulator reference; the plan instead extends the existing dfps/ package.
